# 📚 Library Management System

A simple and efficient **Library Management System** developed to automate and manage library operations digitally. This project helps librarians manage books, students, issuing/returning records, and overall library activities with ease.

## 🚀 Features

* 📖 Add, update, and delete books
* 👨‍🎓 Manage student/member records
* 🔍 Search books easily
* 📕 Issue books to students
* 📗 Return books and update availability
* ⏰ Fine calculation for overdue books
* 🔐 Admin authentication/login system
* 📊 Maintain transaction records

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/akulkarni14/Library-Manegement-System.git
```

### 2️⃣ Move Project to XAMPP/WAMP

Copy the project folder into:

#### For XAMPP

```bash
htdocs/
```

#### For WAMP

```bash
www/
```

### 3️⃣ Start Server

Start:

* Apache
* MySQL

from XAMPP/WAMP control panel.

### 4️⃣ Import Database

1. Open **phpMyAdmin**
2. Create a new database
3. Import the `.sql` file from the project folder

### 5️⃣ Run the Project

Open browser and visit:

```bash
http://localhost/Library-Manegement-System
```
